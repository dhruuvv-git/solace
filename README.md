# Solace

> **Rapid Incident Response Workspace for Non-Consensual Synthetic Media**

Solace is a privacy-first incident triage and evidence-preservation engine designed for the critical "Golden Hour" after digital extortion or synthetic media discovery.

---

## ⚡ Core Capabilities

- **Zero Cloud Exposure:** 100% client-side cryptographic hashing via the Web Crypto API. Media files never leave your local browser memory.
- **Evidence Vault:** Local SHA-256 fingerprinting with court-admissible timestamps for chain of custody preservation.
- **Statutory Takedown Tracking:** Real-time compliance clocks under Indian IT (Intermediary Guidelines) Rules:
  - **Rule 3(2)(b):** 2-Hour Emergency Mandate for non-consensual intimate imagery & impersonation.
  - **Rule 3(1)(d):** 24-Hour Court / Government order enforcement.
  - **Rule 3(2)(a):** 36-Hour Grievance determination.
- **1-Click Legal Notices:** Pre-drafted statutory notices cited with Section 67A IT Act, Bharatiya Nyaya Sanhita (BNS), and Intermediary Guidelines.
- **Emergency Helplines:** Integrated hotlines for the 1930 National Cyber Crime Reporting Portal and NCW.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS + Radix UI
- **Animations:** GSAP + Framer Motion
- **Graphics:** WebGL / Three.js / VGPU
- **Icons:** Lucide React

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/dhruuvv-git/solace.git

# Navigate into directory
cd solace

# Install dependencies
npm install

# Start local development server
npm run dev
```

---

## 🔒 Security & Privacy

All evidence hashing and sealing happens entirely client-side using native browser cryptography. No images, videos, audio clips, or metadata are ever transmitted to any remote server or cloud infrastructure.
